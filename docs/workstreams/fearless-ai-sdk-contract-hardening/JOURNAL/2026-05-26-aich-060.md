# 2026-05-26 - AICH-060 Safe Error Messages

Completed AICH-060.

Changes:

- Documented `LlmErrorExt::user_message()` as safe display copy, not raw diagnostics.
- Removed the fallback from `user_message()` to `Display` for raw string/error variants.
- Added safe generic messages for HTTP, API, provider, parsing, validation, stream, internal, tool,
  unsupported, and contextual errors.
- Kept `Display` and `ErrorSummary.raw` as raw diagnostic surfaces.
- Changed `summarize_error().message` to use safe `user_message()` output while preserving raw
  provider messages/details in `raw` / `details`.
- Guarded normal `format_summary(..., verbose=false)` rendering against raw diagnostic leakage.
- Updated root and `siumai-core` changelogs.

Validation:

- `cargo fmt --check -p siumai-core` passed.
- `cargo nextest run -p siumai-core error --no-fail-fast` passed: 26 tests.

Note:

- This slice preserves compatibility by keeping raw error details accessible through existing
  diagnostics-oriented fields and verbose rendering. The behavior change is that safe display APIs
  no longer expose those raw details by default.
