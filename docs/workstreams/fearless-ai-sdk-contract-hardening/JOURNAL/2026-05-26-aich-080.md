# AICH-080 Usage Snapshot Semantics

Date: 2026-05-26
Status: DONE

## Work

- Documented `Usage` as one provider/model-call cumulative snapshot, not a stream delta.
- Kept `Usage::merge()` as explicit multi-call or multi-step aggregation and documented that merged
  raw provider usage is dropped.
- Changed `StreamProcessor` usage updates to replace earlier same-call finish usage snapshots with
  the latest snapshot, preserving final raw usage and avoiding double-counting.
- Added an OpenAI Responses SSE fixture proving repeated usage events keep the latest cumulative
  snapshot through stream processing.
