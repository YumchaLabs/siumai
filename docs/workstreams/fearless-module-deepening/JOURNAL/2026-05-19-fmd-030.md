# FMD-030 — Provider-id-first classification seam

Date: 2026-05-19
Status: DONE

## Summary

FMD-030 moved primary provider identity away from closed `ProviderType` flows:

- `LlmClient` and `ClientWrapper` now expose `provider_id` only.
- Core parameter validation has provider-id-first entry points and report fields.
- Registry catalog exposes `ProviderInfo::provider_id` and resolves by ids/aliases directly.
- `ProviderType::from_name` is isolated in `siumai-registry::provider::legacy`.
- `ProviderType` remains public but is documented as legacy compatibility classification.
