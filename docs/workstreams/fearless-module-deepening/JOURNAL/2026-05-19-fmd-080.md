## Decision

Do not open the breaking `ContentPart` namespace-move child workstream yet. Continue this lane with
FMD-090 as a non-breaking request-side bridge adapter extraction proof slice.

The decision is recorded in
`docs/workstreams/fearless-module-deepening/FMD-080-content-part-directional-boundary-decision.md`.

## Rationale

ADR-0008 keeps legacy `ContentPart` as compatibility-only but defers moving it until more request
and response adapters cover high-value paths. The older `fearless-content-part-boundary-split`
workstream reached the same conclusion and closed with a future-breaking-slice trigger.

Current code still has legitimate stable uses of `ContentPart` in serde-facing `ChatMessage` /
`ChatResponse`, protocol response transformers, bridge inspectors/serializers, and facade fallback
projection paths. A public namespace move now would be wider than this module-deepening lane.
