# 2026-05-25

## RTBI-010

- Opened the lane after rejecting immediate deletion of deprecated broad
  `registry::factory::build_*_client(...)` helpers because ADR-0007 retirement gates are not ready.
- Targeted a narrower ownership cleanup: move production typed helper implementation out of the
  public legacy `registry::factory` module.
- Initial production call inventory includes OpenAI-compatible, Gemini, Anthropic Vertex, Google
  Vertex, Vertex MaaS, Fireworks, DeepInfra, TogetherAI, and Google Vertex xAI factory paths.

## RTBI-020 / RTBI-030

- Added a source guard that rejects production provider factory calls to typed helpers through
  `crate::registry::factory`.
- Moved typed provider-client builder implementation into internal `registry::typed_builders`.
- Migrated built-in production factories to `crate::registry::typed_builders::*`.
- Kept `registry::factory` typed helper paths as compatibility wrappers rather than deleting them.

## RTBI-040

- Updated architecture and changelog notes to describe `registry::factory` as a compatibility
  wrapper surface and `registry::typed_builders` as the internal implementation owner.
- Closed the lane after focused source guard and all-features registry compile gates passed.
