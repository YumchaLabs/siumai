# 2026-05-21 — FCAB-040

Completed the built-in provider factory projection cleanup.

## Changes

- Added typed-client `Arc` projection helpers to the built-in factories that repeated
  `build_*_with_ctx(...)` + `Arc::new(...)` in family and compatibility methods.
- Centralized checked OpenAI-compatible projection in
  `OpenAICompatibleProviderFactory::build_checked_text_family_model_arc(...)`.
- Centralized native OpenAI projection in `OpenAIProviderFactory::build_family_model_arc(...)`.
- Centralized promoted hybrid vendor projection helpers for:
  - DeepInfra text and provider-owned image clients;
  - Fireworks text and provider-owned image clients;
  - TogetherAI text, provider-owned image, and provider-owned rerank clients.
- Extended the same projection-locality pattern to Azure, Anthropic, Gemini, Google Vertex,
  Google Vertex MaaS, Google Vertex xAI, Groq, xAI, DeepSeek, MiniMaxi, Ollama, Cohere, Bedrock,
  and Anthropic Vertex factories.
- Added architecture source guards in
  `siumai-registry/tests/factory_architecture_boundary_test.rs` to prevent the repeated projection
  glue and same-family `compat_language_client_with_ctx(...)` shortcuts from returning.
- Updated `seam-inventory.md`, `registry-without-builtins.md`, and `public-surface.md` with the
  new factory projection rule.
