# FCAB-120 Journal — Facade Public Surface Finalization

Date: 2026-05-21

## Scope

FCAB-120 tightened the `siumai` facade boundary after the registry, content, provider-utils, and
bridge seams had been deepened. The goal was to keep `prelude::unified` small, keep compatibility
and experimental paths explicit, and document every retained broad export.

## Implementation

- Added `siumai-provider-utils` as a direct facade dependency so root utility helpers can be
  re-exported from their implementation owner instead of from `siumai-core::utils`.
- Moved `ToolNameMapping` / `create_tool_name_mapping` implementation to
  `siumai-provider-utils::standards`; `siumai-core::standards::tool_name_mapping` is now a
  compatibility alias.
- Narrowed `siumai::prelude::unified` by demoting broad provider-utils helper groups to explicit
  root imports. The stable prelude keeps schema helpers, ID generation, stop-condition helpers, UI
  predicates, `SerialJobExecutor`, and `ToolNameMapping`.
- Replaced the experimental grouped core mirror with named modules:
  `experimental::{defaults,execution,observability,params,retry,utils}`.
- Updated public-surface and migration docs to explain provider-utils-backed root helpers, demoted
  unified-prelude imports, and retained broad namespaces.
- Updated public surface compile/source guards.
- Fixed stale tests that still relied on legacy `ContentPart` being in broad preludes by importing
  compatibility content explicitly.

## Validation

See `EVIDENCE_AND_GATES.md` for command evidence. The task-local public-surface gate, facade source
guards, provider-utils package tests, and `siumai` all-test compile gate passed.
