# FCAB-100 Journal — Provider-Utils Deepening And Classification

Date: 2026-05-21

## Scope

FCAB-100 continued the provider-utils isolation started in FCAB-090. The task goal was to move
remaining protocol/provider utility imports to the provider-utils seam and classify the leftover
`siumai-core::utils` surface as stable, experimental, or compat.

## Implementation

- Deepened `siumai-provider-utils` so it now owns the AI SDK-style spec-only helper set:
  - `data`
  - `download`
  - `error_message`
  - `headers`
  - `id`
  - `json_instruction`
  - `json_parse`
  - `option`
  - `provider_options`
  - `provider_reference`
  - `reasoning`
  - `runtime`
  - `serial_job`
  - `settings`
  - `utf8_decoder`
  - `validate_types`
- Kept the FCAB-090 moved modules in the same crate:
  - `builder_helpers`
  - `chat_request`
  - `mime`
  - `url`
- Converted matching `siumai-core::utils::*` files into compatibility aliases backed by
  `siumai-provider-utils`.
- Rewired the remaining TogetherAI config API-key helper import from
  `siumai_core::utils::builder_helpers` to `crate::provider_utils::builder_helpers`.
- Classified the remaining core-owned utility implementations:
  - `cancel` stays stable core runtime because it wires `CancelHandle`, `ChatStream`, and
    `ChatStreamHandle`.
  - `streaming_tool_call` stays explicit compatibility helper because it assembles core stream parts
    and is surfaced through `siumai::compat::*`.

## Guards

- Expanded `provider_utils_crate_owns_high_churn_provider_helpers` to cover all moved
  provider-utils modules.
- Added `core_utils_remaining_owned_modules_are_classified`.
- Added `provider_protocol_crates_do_not_import_moved_provider_utils_from_core`.
- Refined the core source dependency guard so `siumai_provider_utils` is the only permitted
  `siumai_provider_*` import in `siumai-core`.

## Documentation

- Added `provider-utils-classification.md`.
- Updated `seam-inventory.md`, `MILESTONES.md`, and `module-split-design.md` to describe the
  deepened provider-utils crate and the two remaining core-owned utility classifications.
