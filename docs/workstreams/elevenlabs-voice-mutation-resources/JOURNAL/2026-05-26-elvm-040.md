## Split

`edit_voice` remains split from this slice. It shares multipart mechanics but has a path parameter,
different required/optional fields, `moderate_metadata`, and a status response. Keeping it separate
keeps the IVC creation API small and avoids a request type with endpoint-specific null fields.
