## First Slice

ELVM-020 implements settings get/update:

- `GET /v1/voices/settings/default`
- `GET /v1/voices/{voice_id}/settings`
- `POST /v1/voices/{voice_id}/settings/edit`

This slice is the smallest mutation that proves JSON resource POST wiring on `ElevenLabsVoices`
without introducing multipart uploads, DELETE helpers, or PVC workflow state.
