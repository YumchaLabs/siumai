## Work

- Extracted `TerminalEventBuffer` in the Responses SSE converter.
- Moved terminal `Finish` / `StreamEnd` queue ownership out of the converter struct's raw
  `Arc<Mutex<VecDeque<_>>>` field.
- Kept the existing converter helper methods so call sites remain stable for the next slices.
- Extracted `converter::replay` so PartWithReplay attach/apply rules own OpenAI Responses
  `outputIndex` and `rawItem` replay hints.
- Moved replay overlay from the serializer branch into the replay module.
- Extracted `ReasoningLifecycleState` so reasoning encrypted content, emitted starts/ends,
  conclusion deferral, and item-to-part-id tracking are owned by the reasoning lifecycle module.
- Extracted `ProviderToolState` and `CustomToolState` so provider-defined tool names, shell
  provider-executed ownership, hosted tool-search pairing, custom tool aliases, input accumulation,
  and custom tool de-duplication are no longer raw converter fields.
- Removed the custom tool call-name-by-item-id map because it was only written and never read.
- Extracted `OpenAiResponsesSerializeStateCell` and moved serializer state transitions for sequence
  numbers, output indexes, provider tool output indexes, reasoning items, function calls, and
  message items onto `OpenAiResponsesSerializeState`.
- Added root and protocol changelog entries for the AISD follow-up seam-deepening workstream.
