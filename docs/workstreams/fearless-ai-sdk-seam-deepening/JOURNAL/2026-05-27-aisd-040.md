# AISD-040 Journal - Provider-Executed Tool Ownership

Date: 2026-05-27

## Summary

- Added `ToolExecutionOwner` as the shared semantic contract behind AI SDK `providerExecuted` and
  `isProviderExecuted` wire flags.
- Kept existing public wire fields for compatibility, but added owner helpers on provider tools,
  prompt tool-call/approval parts, stream tool calls, UI tool parts, legacy `ContentPart` tool
  views, and borrowed tool info views.
- Routed core UI conversion and stream response assembly through the owner contract so
  `Some(false)` remains an explicit caller-owned override.
- Routed OpenAI Responses request/response/SSE provider-owned tool decisions through the shared
  contract and removed the obsolete ignored `provider_executed` parameter from stream tool-result
  event construction.
- Updated root/spec/core/protocol changelogs.
