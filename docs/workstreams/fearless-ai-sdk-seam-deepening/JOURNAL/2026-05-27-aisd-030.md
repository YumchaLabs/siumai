# AISD-030 Diagnostics Projection

Date: 2026-05-27
Status: DONE

## Work

- Added provider metadata public projection helpers that recursively strip reserved raw/private,
  diagnostic, header, body, request, and response keys.
- Added public projection helpers for `ChatResponse`, `ChatStreamPart`, and `ChatStreamEvent`.
- Routed `StreamProcessor` final content assembly through the provider metadata projection so
  stream part metadata cannot leak raw/private fields into final content parts.
- Added a Responses SSE diagnostics regression proving replay raw items remain private and public
  projection returns a stable part without replay diagnostics.
- Updated root, spec, core, and protocol changelogs.
